# Advent of Code 2026

Back again for another year of Advent of Code. This year I'm also picking up [Everybody Codes](https://everybody.codes/), since apparently one puzzle a day wasn't enough.

I'm doing both in Rust and Lean. Rust because it's fast and I enjoy fighting the borrow checker; Lean because I want an excuse to do some real dependently-typed programming, and nothing motivates learning a proof assistant like a daily puzzle with a known-good answer to check yourself against.

Previous years, for the curious: Python ([2025](https://github.com/threeifbyair/advent2025)), CPP2 ([2024](https://github.com/threeifbyair/advent2024)), Swift ([2023](https://github.com/threeifbyair/advent2023)), and Rust ([2022](https://github.com/threeifbyair/advent2022) -- never finished, maybe this is the year I go back and fix that).

Bring on the elves (and whatever Everybody Codes brings)!
